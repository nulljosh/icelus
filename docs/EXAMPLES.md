# Worked examples

Each example is a small flow typed in Icelus's syntax, the same lines an agent writes for
`sketch_to_wireframe`. Every one passes `critique_project` with nothing to fix: each form shows what a
wrong entry looks like and each list has an empty state. This file is generated by `node tools/examples.mjs`.

## Sign in flow

Read it as a project: `resources/read` with `icelus://examples/sign-in`.

**Sign in**, typed:

```
# Sign in
"Email"
"Password"
[x] Remember me
[Sign in]  [Create account]
Forgot password?
```

**Create account**, typed:

```
# Join
"Name"
"Email"
"Password"
[ ] Send me product news
[Create account]
```

**Reset password**, typed:

```
# Reset
We will mail you a link.
"Email"
[Send link]  [Back]
```

**Wrong password**, typed:

```
# Sign in
"Email"
"Password"
That password is wrong.
[Try again]  [Reset it]
```

## Onboarding

Read it as a project: `resources/read` with `icelus://examples/onboarding`.

**Welcome**, typed:

```
# Hello
Sketch a screen in plain text.
[Get started]
```

**Pick topics**, typed:

```
# Topics
[x] Design
[ ] Code
[x] Writing
[Next]  [Skip]
```

**All set**, typed:

```
# Done
Your first screen is waiting.
[Open the canvas]
```

## Inbox with empty and error states

Read it as a project: `resources/read` with `icelus://examples/inbox`.

**Inbox**, typed:

```
# Inbox
"Search"
| From | Subject |
| Ada | Lunch? |
| Grace | The build |
[Compose]
```

**Empty inbox**, typed:

```
# Inbox

Nothing here yet.
New mail shows up here.

[Compose]
```

**Offline**, typed:

```
# Inbox
Something went wrong loading mail.
The error is on our side.
[Try again]
```
