## What's New
Copy. Every word on the canvas in one list under More. Edit any of it there and only those words change.

Access check. Review now flags controls that focus would visit out of reading order, fields with no label, and controls too small to tap. Fix Focus Order sorts them in one step.

Inspect. Pick a part and open More: where it sits, its size, the gap to its neighbours on each side, and its own React or SwiftUI code to copy.

Grids. Select a screen and set Columns and Gutter. Faint column bands appear inside it, and a part you drag snaps onto a column. Use on Every Screen gives the rest the same grid.

Libraries. Make parts into symbols and copy them as a library. Paste it into any project and its parts join Mine. Paste a newer version and every linked copy updates, except what a copy owns.

Variables and modes. Under More, Canvas has a Lines switch: draw every part in ASCII, single, heavy, double or rounded lines at once, and switch back any time. Add a named spacing value and bind a screen's gap or padding to it. Change it once and every screen using it restacks.

Properties. Select a copy of a symbol and turn on Own words or Own style. Swap puts another symbol in its place, right where it sits.

Sizes. Select a screen and tap Make sizes: phone, tablet and desktop widths side by side, kept in step.

Auto layout and constraints. A screen's parts stay stacked with an even gap. Pin a part and it follows when the screen is resized.

Harmonize, heal and expand. A dropped part takes on the look of its screen. Delete a box in a flow and its arrows join up.

Actions and History. Record a few edits and play them on any part. Every step listed by name, tap one to go back.
