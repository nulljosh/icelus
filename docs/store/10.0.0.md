## What's New
Blockprint is now Icelus. Same app, same files, a new name and icon.

Screens. Put several screens side by side, each a named frame that carries its parts when you move it. Draw an arrow from a button to the next screen, then Copy all screens to get the whole flow as one document. Start from a template: sign in, settings, list, detail or empty state. Pinch to zoom.

Make it yours. Highlight a part in the accent color, save any part to your own palette, and pick from part packs in the style of iOS, Material, the terminal and email. Copy HTML hands the layout to a developer as real buttons, inputs and tables.

Bring it in. Paste any text wireframe, from a README, a chat or another tool, and it becomes parts you can edit. Two Shortcuts actions draw a screen from typed lines and turn box characters into plain ASCII.

For everyone. Icelus now speaks 27 languages, right to left included, and VoiceOver reads every part on the canvas.

Photos. The Photo tool turns any picture into block-character art you can paste anywhere, and Trace a photo puts one faintly under the grid so you can draw over it.

Draw the lines between things. The Arrow tool draws a line from one part to another, and when you move a part, its arrows follow. Where lines cross, the characters join up cleanly.

Type a whole screen. Pick Type it, write a few lines like "Email" and [Sign in], and Icelus draws them as real parts. Copy as typed lines turns any sketch back into those lines.

Fourteen new parts, 37 in all, plus text boxes, big block-letter banners, snap and alignment guides, and five box styles.

## Description
Sketch a screen in plain text.

Pick a part, tap the grid, and it lands there in box-drawing characters. Buttons, inputs, tables, date pickers, tab bars, charts, 37 parts in all. Draw arrows between them, add a big title, and move things around until the screen looks right. Or type the whole screen in a few lines and let Icelus draw it.

Then copy it. A Icelus sketch is text, so it pastes into a pull request, an issue, a README, a chat or a code comment, and it stays editable wherever it lands. No image to attach, no design file to open.

What you get:
- 37 parts, each its own object you can move, resize, duplicate and reorder
- Several screens on one canvas, linked by arrows, copied as one document
- Screen templates: sign in, settings, list, detail, empty state
- Highlights, your own saved parts, and iOS, Material, terminal and email packs
- Copy HTML: the layout as real elements for a developer
- Paste any text wireframe and edit it
- Shortcuts: Draw a screen, Make plain ASCII
- 27 languages and full VoiceOver support
- Arrows that stay attached when parts move
- Type a screen in a few lines, and copy any sketch back as those lines
- Turn a photo into block art, or trace over one
- Text boxes, banners and five box styles
- Snap and alignment guides
- Copy as text, Markdown or plain ASCII, or share an image
- Autosave and 50 steps of undo
- Keyboard control on the Mac
- The same project file on iPhone, iPad, Mac, Apple Watch and the web

Everything stays on your device. No account, no tracking.

One price, no subscription. The web version at icelus.jaybulb.com is free.
