Title: Show HN: Icelus – a design tool whose screens are plain text, with an MCP server

URL: https://icelus.jaybulb.com

Body: I wanted screens that live in pull requests and READMEs instead of image attachments. Icelus is
a design tool (describe a screen and it draws, or edit on a real canvas) where underneath every part (button, table, modal) is a small template of box-drawing characters you can
move and resize, and the output is just text. A project is a short JSON list of elements, and the same
engine is ported line for line to Swift, so the web, iOS, Mac, Watch and a terminal tool all open the same
file. There is a stateless HTTP API and an MCP endpoint on Cloudflare Pages Functions, so an agent can place
parts and render a screen without a database. Free on the web, no account.
