## First comment

Hi, I'm Joshua. I kept wanting to show a layout in a pull request or a chat, and every time it meant a
screenshot from a design tool that nobody could edit and nobody would update. A screen kept as text
just goes where the words go. So I built Icelus, and it grew into a design tool you can talk to: say what
the screen is for and it draws one.

You can also pick a part, a button or a table or a modal, and stamp it on the canvas, where it looks like the
real control. Underneath it is a character grid, and one switch shows it that way. Each part stays its own
object, so you can drag it, resize it, duplicate it and stack it. When it looks right you copy it as text,
as a Markdown block, or as plain ASCII for places that cannot draw boxes.

The same engine runs on the web, iPhone, iPad, Mac, Apple Watch and the terminal, and they all save the same
small JSON project file. There is also an HTTP API and an MCP server, because agents are writing more of
our specs and they should be able to sketch the screen too.

The web app is free and needs no account. The App Store version is $0.99 once. I'd love to hear what part
you reach for that isn't there yet.
