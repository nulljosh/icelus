# Directories (submit once each, by hand)

Name: Icelus

One-liner: Describe a screen and it draws. A design tool with text underneath.

Description: Icelus is a design tool for screens. Describe one in a sentence and it draws, then edit it on a
real canvas with a brush, selections, gradients, color and layers. Every screen is text underneath, so it pastes
into a pull request, README or chat and stays editable. Lay out whole flows, or paste any text wireframe back in. Web, iPhone, iPad, Mac, Apple Watch and the terminal, in 27 languages, with
an API, an MCP server, Shortcuts actions and a GitHub Action.

Category: Design tools, AI design, wireframing

Links: https://icelus.jaybulb.com · https://apps.apple.com/app/id6794988951

Where: AlternativeTo (as an alternative to ASCIIFlow, Monodraw, Balsamiq), Uneed, SaaSHub, Indie Hackers
products, There's An AI For That (for the MCP and API), and MCP server lists (mcp.so, Smithery, Glama).
