Show HN: Icelus: Sketch an interface out of plain characters

Every wireframe tool exports an image nobody can edit in a pull request or a chat. Icelus draws the wireframe out of characters. Pick a component, place it on the grid, copy. It pastes into a README, an issue, a commit message, a Slack thread, and stays editable everywhere. $0.99 on the App Store, free on web. Web at wiretext.jaybulb.com, source on GitHub.
