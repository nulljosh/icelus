A design tool you can talk to.

      
Say what a screen is for and it appears. Then change it the way you would in Figma or Photoshop. Every screen stays text underneath, so it lives next to your code.

    

    

      
Describe it
Open Describe, say what a screen is for, and it lands on the canvas. Pick a screen, say what to change, and it redraws. On the web today.

      
A real canvas
Buttons, fields, switches, menus and tables look like the real thing, on artboards. 38 parts, and charts drawn from your numbers. One switch in Settings shows every part as characters.

      
Paint, pick, adjust
A brush and an eraser. Selections with a marquee or a magic wand. Gradients, 16 colors, masks, and adjustment layers that change what is under them without touching it.

      
Move, resize, edit
Drag a part, nudge it, double-click to change its words. Group, hide and lock layers. Make a symbol and edit every copy at once. Show a part pressed, disabled or in error.

      
Paste anywhere
Copy as text, Markdown, plain ASCII or ANSI color. Hand a developer real HTML, or share a link anyone can embed. Autosave keeps your work, and a project file opens on any device.

      
Code and decks
Copy a screen as a React component or a SwiftUI view. Hand Claude Code one build brief. Present your screens full screen and save the deck as a PDF.

    

    

      
Whole flows
Put screens side by side, link them with arrows, copy the flow as one document.

      
Type it or paste it
Write a few lines, or paste a wireframe from a README. You get parts you can edit.

      
Native too
SwiftUI on iPhone, iPad, Mac and Apple Watch. Same project file as the web.

      
For everyone
Everything works from the keyboard and VoiceOver reads the canvas. 27 languages, right to left included.

    

  






  

    

      
Text underneath

      
Agents can draw.

      
Every screen is text on a character grid. It is the same screen you see on the canvas, and it pastes into a README, a chat or a commit.

      
Claude or any assistant gets the same thing over an API and an MCP server, with worked examples and prompts. It can sketch, review and fix a screen. A GitHub Action keeps README wireframes whole.
